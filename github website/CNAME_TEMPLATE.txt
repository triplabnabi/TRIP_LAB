# Custom Domain Setup for TR(i)P Lab Website
# This file contains instructions for setting up a custom domain

# To enable a custom domain for your GitHub Pages site:
# 1. Choose a domain name (e.g., trip-lab.org, lab-name.edu)
# 2. Point your domain's DNS to GitHub Pages
# 3. Rename this file from CNAME_TEMPLATE.txt to CNAME
# 4. Replace "your-domain.com" with your actual domain name

# For example:
# trip-lab.org

# DNS Configuration:
# Type: CNAME
# Name: www (if using www subdomain)
# Name: @ (for root domain)
# Target/CNAME: yourusername.github.io

# Or for APEX domain (trip-lab.org):
# 1. Configure A Records pointing to:
#   - 185.199.108.153
#   - 185.199.109.153
#   - 185.199.110.153
#   - 185.199.111.153
# 2. Set CNAME value to yourusername.github.io

# Important Notes:
# - Wait 24-48 hours for DNS propagation
# - Ensure you have access to your domain's DNS settings
# - If using a subdomain, add it before the extension
# - GitHub Pages will automatically add HTTPS to custom domains

# Contact:
# If you need help with DNS configuration, please contact your domain registrar
# or hosting provider for specific instructions.
